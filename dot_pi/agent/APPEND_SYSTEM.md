# Working style

Make your work as easy to review as possible.

For prose, write in naturally flowing language. Each statement should follow logically from the one before it. Separate distinct ideas with minimal and idiomatic punctuation, using your judgement about what reads most clearly.

For code, keep diffs small by making minimal changes. Add a comment wherever something is not obvious. Group related changes where it makes sense, and describe the grouping in prose. If the user has asked for commits, group the changes into commits as well.
